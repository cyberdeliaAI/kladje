# Kladje feature matrix

**Reviewed on the P1 branch from 294ed47, 23 November 2026.** Rows citing audit line numbers retain their original evidence at 15095ca. The P0 and P1 rows below reflect the current implementation. Complete means the stated, bounded workflow passed a check. Partial means a useful subset exists with an identified gap. Broken means the expected behavior fails in an observed case or necessarily takes the wrong branch. Missing means no implementation was found in the tracked product. Unverified means an implementation or claim exists and the available checks could not settle it. Native observations apply to macOS. A passing unit test covers its fixtures only.

**Priority and cost.** P0 protects work and trust boundaries. P1 is essential for a stable editor. P2 improves frequent workflows, with Recent and heading navigation selected for v1. P3 is optional and P4 is deferred. Cost is the estimated size of the recommended next change, including verification. Low, Medium and High are relative to this repository.

**Evidence key.** Numbers after a filename abbreviation are source lines. **Native** means an interaction in the real application, **test** an existing Rust test, **probe** a focused audit check, and **source** an inspection finding. The [audit](PROJECT_AUDIT.md) describes the checks and their limits.
