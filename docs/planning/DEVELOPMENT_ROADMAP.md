# Kladje development roadmap

**Planning baseline · 23 November 2026 · 15095ca.** Start with the failing save cases. The macOS editor already supports ordinary writing, live preview, find/replace, history and PDF output. The fastest path to a credible release is to make document handling dependable, then qualify those existing workflows on the platforms Kladje intends to support.

Each numbered step below can ship as a separate change with its own regression test. Effort assumes one developer familiar with Rust, JavaScript and Tauri, access to native test machines and timely product decisions. The ranges estimate engineering effort. For P0–P2, allow additional calendar time for native QA and distribution. The [audit](PROJECT_AUDIT.md) supplies evidence, the [matrix](FEATURE_MATRIX.md) defines feature scope, and the [vision](PRODUCT_VISION.md) lists owner decisions.

## P0 · Protect documents and close known failures

**Goal.** A normal save, failed save, external edit, dropped file or restart always leaves the user with an identifiable copy of their work. A person opening a Markdown file controls what resources it loads. **Complexity High · roughly 2–4 engineer-weeks.** Start with steps 1–2 together. The first delivery is a safety fix with measurable value even before recovery is replaced.

**Build and test record.** The locked Rust suite passed 35 tests and the JavaScript lifecycle suite passed 14. The development server example compiled. A locked offline npm install reproduced the checked-in editor bundle byte for byte. The Tauri release build produced an Apple silicon macOS app using `npm run build -- --ci --bundles app`.

**Native evidence.** Saved a UTF-8 BOM/CRLF file through its symlink and checked the target bytes. Changed it externally, attempted Save, force-killed the editor, restored the draft, and used Save As. Verified the external original and recovered copy independently, including BOM and line endings. The symlink survived and the saved draft retired from recovery.

**Operating limits.** Document reads and encoded saves are limited to 64 MiB. Recovery schedules a write after 900 ms idle or after five seconds of continuous typing. A crash can lose input since the last completed write. Each draft keeps up to three generations within 128 MiB after successful publication. Unresolved drafts stay available until saved or explicitly discarded. Save As is the fallback for unsupported atomic-exchange filesystems, Unix hard links and Linux files with extended attributes. An external writer can change a file again after a completed check.

**Readiness.** Proceed with P1 on macOS for the single-document workflow. The P0 publication left preview-resource and renderer security open. The P1 verification record below tracks step 6. Windows and Linux still need native acceptance, including locks, replacement, permissions and recovery. Windows flushes file data and uses OS replacement semantics. Directory-entry power-loss durability remains unqualified there. Real power loss, removable media, network shares, cloud-sync races and distribution signing/install remain manual qualification work.

## Independent review follow-up

On a disposable macOS exFAT volume, atomic exchange, exclusive rename, clone and hard links returned ENOTSUP. A normal rename after a digest check could erase a competing writer's file. Kladje keeps its original exchange path and offers a protected copy for either an existing document or a new name on an incompatible volume. It flushes the encoded file and its staging directory, publishes the complete directory beside the requested path, then verifies the destination and flushes the parent. After consent the editor follows the new path. Relative references use that new folder. Cancellation and uncertain writes retain unsaved work. Existing-file in-place updates on exFAT, network shares and physical unplug/power loss remain unqualified. HTML exports and attachments use the same complete-folder strategy when necessary. The macOS CI fixture mounts an actual exFAT image. Windows and Ubuntu have separate native compile jobs.


### Writing and illustrated documents

Implemented opt-out pairing and HTTP(S) link paste, opt-in HTML-to-Markdown paste, formatted copy, Markdown task toggling, table-cell navigation, heading folding, four embedded fence languages, metadata-aware editing and counting, selection statistics, optional reading time and writing settings. Close Window and Use Selection for Find follow macOS shortcuts. Reveal in Finder uses the saved document path. HTML-to-Markdown uses the existing importer. Formatted copy on macOS publishes two representations using AppKit. The non-macOS clipboard path still requires native acceptance.

Preview updates send validated local image payloads only when needed. On Unix a bounded cache reopens a confined file handle and checks its identity and change timestamps before reuse.
